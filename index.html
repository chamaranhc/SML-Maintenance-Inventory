Database Connection & Rules

Project: sml-otd (Realtime Sync Active)

If your Firebase project (sml-otd) shows Missing or insufficient permissions, your Firebase Console security rules are currently blocking client read/write access. While locked, this dashboard automatically syncs in real-time across browser tabs locally.

Option 1: Firebase Realtime Database Rules (sml-otd-default-rtdb) 
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
Option 2: Cloud Firestore Rules 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
